04

States and the one dangerous action

Every state has a sentence a non-technical user can act on. Delete asks for the phone's name, not a checkbox — because it is the only irreversible thing here.

State pills
running booting stopped needs you

needs you = quota exhausted, no KVM, or the slot was deleted on GitHub. One sentence + one fix button.

Empty state
No phone yet
First boot takes 60–160 s. After that, 15 s.

No "loading spinner of doom": the first boot is slow and we say so before it starts.

Danger tab · delete codespace

Delete phone-7f2a?

This deletes the codespace behind the phone. Apps, screenshots, and the saved snapshot are erased. There is no undo, and no backup is kept unless you made one.

Usage
Deliberate omissions. No settings page in v1 (machine type and idle timeout are set at create and shown, not edited). No chat box — the agent lives in the user's own terminal. No billing UI: the meter links to GitHub instead of pretending we control the quota.
One rule for every screen: say what the user's GitHub is doing, never claim we do it for them. That is the entire trust story of a BYO-account product.
