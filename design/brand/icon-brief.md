## Product brief
Emuly: a free Android phone that lives in the cloud (inside your own GitHub Codespace). AI coding agents drive it: they tap, type, take screenshots and check results. Personality: fast, clever, a little playful, trustworthy for developers. The icon must say "a phone that an agent controls remotely" in ONE idea, not three.

## Hard rules
- Each icon: 1024x1024 PNG, rounded-square app icon (squircle, about 22% corner radius) filling the canvas edge to edge with a plain transparent-looking or solid neutral outside corner area. No text, no letters except where a concept asks for a letterform, no mockups, no hands, no device photos, no busy scenes.
- One core concept made from 2-3 simple shapes. Must still read at 32px. Check this by mentally shrinking it.
- Crisp, vector-clean edges. Centered optical balance. Consistent stroke weight where strokes exist.
- Avoid clichés: no generic phone outline alone, no Android robot, no cloud clip-art, no circuit lines, no glowing neon, no random sparkles.
- Colours do NOT need to match any existing app. Choose bold, modern, distinctive palettes. Every icon in a set uses a different palette.

## Concept seeds (pick the 6 strongest, reinterpret freely)
- A tap: a pointer/cursor tip pressing a phone-shaped tile, with one clean ripple ring.
- A remote phone: a phone tile floating above a soft shadow, one corner peeling into a second layer (local + cloud twin).
- An agent spark (4-point star) acting as the phone's screen light.
- A lowercase "e" whose counter is a phone screen.
- A phone tile rotated 12 degrees with a bold orbit arc around it (always on, in the cloud).
- A play/run triangle cut out of a phone tile (run a phone).
- Two stacked rounded tiles forming a stepped "E".
